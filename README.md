# Қазақ тіліндегі эссені AI арқылы тексеру

FastAPI интерфейсті де, API-ді де бір портта береді. Браузерде бөлек бағалау алгоритмі жоқ. Ортақ ережелер мен маркерлер: [docs/essay-rules.md](docs/essay-rules.md), `Дипломдық жұмыс/backend/rubric.json`.

## Орнату және іске қосу

Python 3.12 және Node.js (JavaScript синтаксисін тексеру үшін) қолданылады.

```bash
python -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
```

Сервер процесіне `ESSAY_AI_API_KEY` құпия айнымалысын қауіпсіз secret manager арқылы беріңіз. Кілтті кодқа, браузерге, Git-ке немесе чатқа жазбаңыз. `ESSAY_AI_MODEL` міндетті емес; әдепкі модель — `gemini-3.8-flash`. Модельге қолжетімділік пен төлем лимитін API аккаунтында тексеріңіз.

```bash
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -m uvicorn main:app --app-dir 'Дипломдық жұмыс/backend' --host 127.0.0.1 --port 8000
```

Бөлек `http.server` қажет емес. Бір сервер интерфейсті және `/api/analyze`, `/api/rubric`, `/api/health` маршруттарын береді. `health.aiConfigured` айнымалының бар екенін ғана көрсетеді; кілттің жұмыс істейтінін дәлелдемейді. Шығыс желіге `generativelanguage.googleapis.com:443` қажет. Қосымша Google Fonts қолжетімсіз болса, жүйелік қаріп қолданылады.

## Талдау

Тақырып, мәтін, эссе түрі, стиль, көлем және аудитория жіберіледі. AI JSON Schema бойынша жауап береді. Сервер бес критерийді және балл шектерін тексеріп, жалпы баллды өзі қосады. Мәтінде жоқ AI үзінділері қабылданбайды. Маркерлер — тек көмекші белгілер. API кілті болмағанда жалған немесе ережелік «AI нәтижесі» көрсетілмейді.

Талдау үшін мәтін Google Gemini қызметіне жіберіледі. Тарих ең көбі 30 жұмысты осы браузерде сақтайды; дерекқорға жіберілмейді. PDF браузердің басып шығару терезесіндегі PDF сақтау арқылы алынады; бөлек CDN кітапханасы қажет емес.

## Тексеру

```bash
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -m unittest discover -s 'Дипломдық жұмыс/backend/tests' -v
node --check 'Дипломдық жұмыс/app.js'
```

Тесттер AI жауабын алмастырады: нақты API шақырмайды және қазақша бағалау сапасын дәлелдемейді. Нақты дайындық үшін жарамды кілтпен бір эссені тексеріп, бес критерий мен мәтіннен алынған үзінділерді бағалау қажет. Мұғалім бағасымен салыстыру бөлек зерттеу кезеңі.

Қазіргі іске қосу жергілікті әзірлеуге арналған. Интернетке ашық орналастырмас бұрын пайдаланушыларды сәйкестендіру, сұраныс квоталары және шығын лимиттері қажет. Бір уақытта екі талдау шектеуі жалпы API бюджеті лимитін алмастырмайды.

Gemini native generateContent API қолданылады; бұл OpenAI ақылы қызметіне сұраныс жібермейді. Тегін квота модельге, жобаға және өңірге байланысты, шексіз емес. ESSAY_AI_API_KEY құпиясының destination домені generativelanguage.googleapis.com болуы тиіс.
